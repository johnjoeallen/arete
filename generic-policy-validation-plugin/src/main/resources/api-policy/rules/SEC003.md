# SEC003 — Sensitive data is embedded in a path parameter

Sensitive identifiers or credentials should not be placed in a URL path,
where the complete URL is frequently logged and retained.

```yaml
parameters:
  - name: access_token
    in: path
    required: true
    schema: { type: string }
```
