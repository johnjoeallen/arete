# SEC008 — Sensitive data is carried in a custom header

Sensitive values in headers should be explicitly reviewed because headers are
often logged or forwarded by infrastructure.

```yaml
parameters:
  - name: X-Api-Key
    in: header
    schema: { type: string }
```
