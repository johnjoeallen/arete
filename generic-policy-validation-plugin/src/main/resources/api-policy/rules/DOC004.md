# DOC004 — Operation summary ends with an unnecessary period

Short operation summaries normally do not require a trailing full stop.

## Detection and scope

The rule has `operation-summary` scope and uses the `text-style` rule:

```yaml
parameters: { trailing-period: present }
```

For every non-empty operation summary ending in `.`, the rule reports an
diagnostic at the operation pointer with `Operation summary ends with a
period`. Missing or blank summaries are ignored by this rule.

## Review-candidate example

```yaml
paths:
  /customers:
    get:
      summary: List customers.
```

## Compliant example

```yaml
paths:
  /customers:
    get:
      summary: List customers
```

## Configuration and limitations

`trailing-period: present` selects this check. The rule checks only the
final character and does not judge abbreviations, decimal values, punctuation
style, descriptions, or business meaning. It does not flag missing summaries;
DOC001 covers that condition. Findings are presentation-style candidates.
