# SEC002 — Sensitive data is accepted in a query parameter

Sensitive values should not be placed in query strings, which are commonly
captured by logs, browser history, caches, and intermediary systems.

```yaml
parameters:
  - name: password
    in: query
    schema: { type: string }
```
