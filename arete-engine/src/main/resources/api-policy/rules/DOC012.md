# DOC012 — API title does not follow the naming convention

## Intent

`info.title` is the public name of the API. It should end with `{{suffix}}`,
use Title Case, and not end with a work-in-progress marker such as
`{{forbidden}}`.

## Diagnostic

```yaml
info:
  title: Token Connect PoC
  version: 1.0.0
```

## Compliant

```yaml
info:
  title: Token Connect API
  version: 1.0.0
```

## Detection and scope

The rule has `api` scope and uses the `api-title` rule. It reports a title
that does not end with `suffix`, whose final word is one of the comma-separated
markers in `forbidden` (case-insensitively), and — when `case: title-case` is
set — any significant word that does not start with an uppercase letter. Short
connector words and tokens of three or fewer characters are ignored by the
case check. A missing or blank title is left to DOC006.

## Configuration and limitations

`suffix`, `forbidden`, and `case` are policy parameters. The case check is a
heuristic and does not enforce a full editorial style guide.
