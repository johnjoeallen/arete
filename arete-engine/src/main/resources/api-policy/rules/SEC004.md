# SEC004 — Search query input may carry sensitive data

## Intent

Free-text search parameters should be reviewed because users may submit
sensitive values that become visible in URLs, logs, and tracing systems.

## Review-candidate example

```yaml
parameters:
  - { name: q, in: query, schema: { type: string } }
```

## Compliant example

```yaml
parameters:
  - { name: filter, in: query, schema: { type: string } }
```

## Detection and scope

The rule has `query-parameter` scope and reports query parameters whose names
match the configured search pattern, such as `q`, `query`, `search`, `term`,
or `text`.

## Configuration and limitations

`search-pattern` selects search-like names. This is a review heuristic; it does
not determine whether a particular search value is sensitive or inspect logs.
