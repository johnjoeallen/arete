    Policies¶

    A policy is the deployable rule set: the list of active rules and what each one costs. The Areté Policy Engine exposes one rule set per policy in the bundle; pick one in the validation picker. The first policy listed here is the default when an unknown rule set is requested.

    qualityScore   = max(0, 100 − Σ deductions for matched rules)
effectiveScore = 0 if any PROHIBITED rule matched, else qualityScore

    Enterprise Grade¶

    The default policy: it enables every generally-applicable bundled rule, with a few rule parameters calibrated for a typical enterprise API (allow-listed proprietary headers, expected OAuth2 scopes, standard rate-limit headers).

    • 111 rules active
    • passing score: 90 (the automation API fails below this unless overridden)
    • grades: A ≥ 95, B ≥ 90, C ≥ 80, D ≥ 70, else F
