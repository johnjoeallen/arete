# SEC007 — Identifier property lacks the required format

## Intent

Identifier properties should declare their representation so generated clients
and validation tooling can handle them consistently.

## Review-candidate example

```yaml
properties:
  customer_id: { type: string }
```

## Compliant example

```yaml
properties:
  customer_id: { type: string, format: uuid }
```

## Detection and scope

The rule has `property` scope and reports identifier-like property names whose
format is not the configured value.

## Configuration and limitations

`check: format` and `format: uuid` select this constraint. The rule does not
validate that values are actually UUIDs or infer a format from examples.
